# nyata-mcp

MCP (Model Context Protocol) server for Nyata AI — exposes Bristol's hyper-local community data as tools for AI agents.

Built by Kush Sharma · DevRel & API Partnerships · Nyata AI

## Status

Spec in progress — implementation coming soon.

## What is this?

nyata-mcp lets AI agents (like Claude) query Nyata's community knowledge directly through the Model Context Protocol — food banks, charities, local events, and support services in Bristol — without needing to call the REST API manually.

## Planned Tools

- Community service search
- Food bank & charity lookup
- Local events discovery
- Postcode/neighbourhood-specific queries
